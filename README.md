# Atelier · 模型工作台

一个 Claude 桌面端风格的本地 AI 模型工作台 Demo。纯前端实现，使用 React + TypeScript +
Vite + Tailwind CSS，交互数据全部在本地模拟。

```bash
npm install
npm run dev        # http://localhost:5273
```

其他命令：

```bash
npm run build       # 类型检查 + 生产构建（输出 dist/）
npm run preview     # 预览生产构建
npm run typecheck   # 仅类型检查
node scripts/shots.mjs   # 用 Playwright 截取全量界面截图到 shots/
```

截图脚本需要系统已安装 Chrome（Playwright 会调用 `channel: chrome`）。

## 界面构成

| 区域 | 说明 |
| --- | --- |
| 侧栏 | 品牌标识、五个页面入口、下载任务角标、账户区；可折叠为 60px 图标栏（`Ctrl+B`） |
| 顶栏 | 面包屑、引擎状态与端口、密度切换、主题切换、帮助 |
| 模型库 | 核心页面：搜索、类型/状态筛选、排序、列表/网格视图、表格行操作 |
| 详情面板 | 点击行打开：状态、操作、参数表、文件信息、运行设置（滑块/开关）、高级选项 |
| 命令面板 | `Ctrl+K` 唤起：模型 + 页面 + 操作三类结果，方向键选择、回车执行、Esc 关闭 |
| 首页 | 问候语、运行概览、收藏、下载队列、引擎状态 |
| 下载管理 | 任务进度、暂停/继续/取消、速度与剩余时间 |
| 运行记录 | 历史会话表格与状态筛选 |
| 设置 | 外观 / 引擎 / 存储 / 隐私与通知 / 快捷键，含开关、下拉、单选、输入等控件 |

## 已实现的交互

- 五个页面切换，面包屑与顶栏状态同步
- 搜索（名称、发布者、量化、参数、标签）与空状态
- 类型筛选、状态筛选、四种排序、列表/网格视图切换
- 点击行打开详情面板，切换模型内容，Esc / 关闭按钮 / 遮罩关闭
- 侧栏折叠与展开（含窄屏抽屉模式）
- 标准 / 紧凑两种信息密度（`Ctrl+D`，设置中亦可切换）
- 浅色 / 深色主题（`Ctrl/J`），偏好写入 localStorage
- 命令面板：分类结果、键盘上下选择、回车执行、空结果状态
- 模型启动 / 停止（含错误反馈与按钮状态变化）
- 下载进度模拟：暂停、继续、取消、完成后自动进入模型库
- 收藏、复制标识、移出工作台（带确认对话框）
- 设置项全部真实生效并持久化：开关、下拉、单选、端口输入、滑块
- Toast 通知：成功 / 错误 / 信息三类，自动消失，可手动关闭
- 快捷键：`Ctrl+K`、`Ctrl+B`、`Ctrl+D`、`Ctrl+J`、`/` 聚焦搜索、`↑↓`、`Enter`、`Esc`

## 设计系统

设计变量集中在 `src/styles/index.css`，分三组：调色板与字体（`@theme`）、
组件类（`@layer components`）、动效关键帧。

- **色彩**：暖白纸感背景 `#FCFCFB`，侧栏 `#F7F6F2`，表面 `#FFFFFF`，
  主文字 `#292825`，陶土强调色 `#D97757`（仅用于主操作与选中态），
  边框为低对比暖灰。深色主题使用同一套语义变量覆盖。
- **字体**：Inter Variable + Noto Sans SC（正文），Newsreader + Noto Serif SC
  （页面标题，少量使用），IBM Plex Mono（路径、校验值、快捷键、参数表数值）。
  数字列统一 `tabular-nums`。
- **间距**：4 / 8 / 12 / 16 / 24 / 32 / 48。列表行高 60px（紧凑 44px），
  页面留白 30px。
- **圆角**：控件 8px，面板与浮层 10–16px，不嵌套圆角。
- **阴影**：极轻的多层阴影，浮层带 1px 暖色描边而非重投影。
- **图标**：Lucide，列表辅助 16px、导航与操作 18px，同语义同图标。

## 第二轮：编辑式极简与精密仪器美学

在第一轮稳定的布局与组件之上，第二轮只调整视觉语言，不改动业务逻辑。

**建立可复用的特色元素**（集中在 `index.css` 的 `@layer components`）：

| 元素 | 用途 |
| --- | --- |
| `.display-hero` | 首页问候的衬线大字，第二行视觉缩进形成非对称构图 |
| `.readout` / `.readout-lg` | 等宽数字读数，用于吞吐、显存、端口、校验值 |
| `.tick-rail` | 刻度线，为图表、进度条、显存条提供度量参照 |
| `.meter-bar` | 细进度/占比条，运行记录页用它做吞吐对比 |
| `.rule-lead` / `.hairline` / `.hairline-strong` | 低对比分割线，用留白建立层级 |
| `.section-tick` / `.sort-marker` | 小节与排序列的陶土标记，替代装饰标签 |
| `.row-name-link` | 行名悬停时从左侧伸长的细线 |

**首页重新构图**：放弃四列统计，改为 1.42 : 0.85 的非对称分栏。
左栏是编辑式标题区（短横线 + 日期 + 44px 衬线问候 + 错位缩进的姓名），
右栏下沉 86px 放置「当前会话」仪表：大号等宽读数、实时吞吐折线
（带 1/4 刻度与「现在」标线）、显存刻度条、GPU 层数与上下文。
「最近使用」改为带细线的账目式列表，不再使用卡片。

**模型库精修**：表头缩小到 10.5px 并显示排序列标记；页面标题右侧加等宽计数；
行名改为常规字重、悬停时浮现下划线；选中态保持陶土左线 + 暖色底。
详情面板新增三格规格条（参数量 / 上下文 / 权重），参数表改为
「小号标签 + 等宽数值」，文件路径前加刻度线。

**扩展到其余页面**：运行记录每行内嵌吞吐对比条；下载管理用刻度线 +
等宽读数；设置分组标题加标记，主题选择改为真实界面的微缩预览
（侧栏条 + 内容线 + 陶土按钮），而不是通用图标。

**刻意没有做的事**：没有加大所有标题、没有添加英文编号与装饰标签、
没有引入背景图案与渐变、没有给每个组件加动画、没有把表格改成卡片。

## 响应式

- 桌面（≥1480px）：详情面板作为分栏，挤压列表宽度
- 中等（1180–1480px）：详情面板转为右侧浮层 + 遮罩
- 列表使用容器查询，宽度不足时依次隐藏「类型 → 上下文 → 量化 → 大小 → 更新」列
- 窄屏（≤760px）：侧栏改为抽屉，顶栏出现菜单按钮，列表退化为三列

## 目录结构

```
src/
  components/
    models/      模型库页面、列表行、网格卡片、详情面板
    palette/     命令面板
    pages/       首页、下载、运行记录、设置
    shell/       侧栏、顶栏、Toast、对话框
    ui/          按钮、开关、下拉、滑块、菜单等基础组件
  lib/           类型定义、模拟数据、工具函数
  store/         全局状态（reducer + Context，含下载模拟与持久化）
  styles/        设计变量与组件样式
```

## 说明

- 演示数据为虚构，下载进度、吞吐等数字由前端定时器模拟，不会访问网络。
- 刷新页面后偏好（主题、密度、侧栏、设置）会恢复；模型与下载状态重置为初始数据。
