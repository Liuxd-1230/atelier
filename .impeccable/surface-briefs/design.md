# Surface brief — /design 审美一览

Scope: standalone full-viewport route inside the deployed app, outside the workbench shell; cross-linked with the workbench (sidebar entry in, back link out). Visitor mode: **Experience**. Audience: 前端同行/社区。语言 zh-CN。

## Direction contract

THESIS — 页面即证据：一览不「谈论」工艺，而是把工作台的真实 tokens、真实组件、真实数据直接作为展品陈列——凡是能活的都在活。它拒绝品类默认（静态截图加解说文字的案例页）；没有任何东西是"本可以是活物却用截图充当"的。

OWN-WORLD — 完整继承 Atelier 既定系统，不新增一个 token：暖纸 canvas #FCFCFB / 墨阶 / 陶土 #D97757 仅用于主操作与选中；Newsreader + 思源宋衬线展示、Inter + 思源黑正文、IBM Plex Mono 读数；hairline / tick-rail / 账目线 / 8-16px 圆角 / 极轻多层阴影 / 编辑式非对称。页面的标注语言（标本编号、说明）复用 .readout / .section-tick / .hairline。

STORY — 同行滚动一个连续的标本抽屉：色彩 → 字阶 → 空间与线 → 交互部件 → 演进对比 → 构建方法 → 尾注。离开时他们相信工艺是真的（因为摸过），并带走 token 名称。

FIRST VIEWPORT — 无营销 hero。顶部即工作台开篇装置的再现：date-line readout + 68px 衬线大字「前端构建审美一览」（第二行缩进装置）+ 一句 thesis；其下第一件活标本已入画：色彩三场（canvas/rail/clay，等宽 hex 读数）与第一条字阶行。右上角真实主题开关（活件承诺的开关本身）。页顶 scroll 进度以 tick-rail 呈现。

FORM — 标本盒长卷（用户在 dealt 手牌中锁定）。code-led 构建（本环境无图像生成）；签名交互命名为「活件承诺」：吞吐图实时流动、开关滑块即真实组件、演进对比为拖拽分割线、全页主题一键翻转证明 tokens 是活的；标本编号（01–07）作为可引用的目录 ID 而存在。

FINISH — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
